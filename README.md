# SCARRY v1 (`alf-scarry`) — Эмулятор картриджа для ТВ-игры «Эльф»

Аппаратный флеш-картридж (эмулятор ПЗУ с банковским маппером до 512 КБ) для 8-битной телевизионной игровой приставки **«Эльф» (ALF TV Game)** на базе процессора Z80.

---

## Основные характеристики ревизии v1 (`EPM240T100C5N`)

* **ПЛИС маппера и SPI-моста:** Altera MAX II `EPM240T100C5N` (корпус `TQFP-100`, задействовано 58 сигнальных выводов).
* **Управляющий микроконтроллер:** Модуль `Raspberry Pi Pico` (`RP2040`, частота ядра 100 МГц, аппаратная генерация 50 МГц на `GPIO21` для тактирования ПЛИС).
* **Оперативная память (исполняемое ПЗУ):** `AS6C4008-55PCN` (512 КБ, организация 512K×8, время доступа 55 нс, питание `+3.3V`).
* **Согласование уровней с 5В шиной Z80:** 4 шинных формирователя `74LVT245` / `74LVC245` в корпусах `TSSOP-20`:
  * `U2` — младшая шина адреса `/*A0 .. /*A7`;
  * `U3` — старшая шина адреса `/*A8 .. /*A13`, а также стробы `/*PBANK` и `/*ROMC/`;
  * `U4` — управляющие линии Z80 (`/*RST/` и резервные линии);
  * `U5` — двунаправленная шина данных `/*D0 .. /*D7` <-> `/D0_33V .. /D7_33V`.
* **Хранение образов игр:** Карта памяти `microSD` (FAT32), поддержка образов `.bin`/`.rom` объемом от 16 КБ до 512 КБ и конфигурационного файла `alf_cfg.ini`.
* **Пользовательский интерфейс:** Графический OLED-дисплей `SSD1306` 0.91" (`128x32`, шина I2C) с анимацией персонажа Альфа (`32x32`) и 3 тактовые кнопки (`UP`, `OK`, `DOWN`) с аппаратным RC-подавлением дребезга.
* **Самодиагностика (BIST):** Автоматическая проверка целостности шины и всех 32 банков SRAM `AS6C4008` при каждом включении питания.

## Инструкция по сборке

### 1. Компиляция проекта ПЛИС (`firmware/cpld_epm240`)
1. Откройте файл `alf_cartridge_top.qpf` (или импортируйте `pins.qsf`) в среде **Altera Quartus II** (поддерживается версия 13.0sp1 или Quartus Prime Lite).
2. Запустите **Start Compilation**.
3. Прошейте сгенерированный файл `output_files/alf_cartridge_top.pof` в микросхему `EPM240T100C5N` через разъем `JTAG` программатором **USB-Blaster**.

### 2. Загрузка прошивки микроконтроллера (`firmware/firmware_pico`)
Самый простой способ — использовать готовый бинарный файл:
1. Зажмите кнопку **BOOTSEL** на Raspberry Pi Pico и подключите его к ПК по USB.
2. Скопируйте файл `scarry.uf2` на появившийся виртуальный диск.

*(Для разработчиков: вы также можете собрать прошивку из исходников, используя `CMakeLists.txt` и установленный Pico C/C++ SDK).*

### 3. Подготовка SD-карты
1. Отформатируйте карту microSD в файловую систему **FAT32**.
2. Скопируйте файл `alf_cfg.ini` из директории `firmware/sdcard_template` в корень SD-карты.
3. Поместите образы игр (`.bin` или `.rom`) в директорию `games` на SD-карте.
