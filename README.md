# SCARRY v1 (`alf-scar`) — Эмулятор картриджа для ТВ-игровой приставки «Эльф»

**КАРТРИДЖ ДЛЯ ЭЛЬФ | BY san010101 | BASED ON zxbyte.org**

Аппаратный флеш-картридж (эмулятор ПЗУ с банковским маппером до 512 КБ) для 8-битной телевизионной игровой приставки **«Эльф» (ALF TV Game)** на базе процессора Z80.

## Основные характеристики ревизии v1

* **ПЛИС маппера и SPI-моста:** Altera MAX II `EPM240T100C5N` (корпус `TQFP-100`).
* **Управляющий микроконтроллер:** Модуль `Raspberry Pi Pico` (`RP2040`, аппаратная генерация 50 МГц для тактирования ПЛИС).
* **Оперативная память (исполняемое ПЗУ):** `AS6C4008-55PCN` (512 КБ, SRAM, питание `+3.3V`).
* **Согласование уровней с 5В шиной Z80:** 4 шинных формирователя `74LVT245` / `74LVC245` (`TSSOP-20`).
* **Хранение образов игр:** Слот для карты памяти `microSD` (FAT32), поддержка файлов `.bin`/`.rom` и автоматическое сохранение последнего выбранного банка в конфигурацию `alf_cfg.ini`.
* **Пользовательский интерфейс:** Графический OLED-дисплей `SSD1306` 0.91" (`128x32`, I2C) и 3 тактовые кнопки (`UP`, `OK`, `DOWN`).
* **Самодиагностика (BIST):** Автоматическая проверка линий данных и ячеек памяти SRAM `AS6C4008` при включении.

## Структура репозитория

* `alf-scar.pdf` — Принципиальная электрическая схема картриджа.
* `gerber.zip` — Готовые производственные файлы (Gerber) для заказа печатных плат.
* `docs/` — Техническая документация:
  * `BOM.md` / `BOM_alf-scar.xlsx` — Спецификация компонентов для сборки платы.
  * `HARDWARE_DESCRIPTION.md` — Описание аппаратной архитектуры.
  * `PINOUT.md` / `raspberry-pi-pico-pinout-2.jpg` — Распиновка разъема приставки, выводов ПЛИС и Raspberry Pi Pico.
* `firmware/cpld_epm240/` — Исходные коды ПЛИС для САПР Quartus II:
  * `alf_cartridge_top.v` — Основной Verilog-код маппера и SPI-моста.
  * `alf_cartridge_top_fixed.v` — Альтернативная (доработанная) версия кода ПЛИС.
  * `pins.qsf` — Файл назначения 58 сигнальных выводов ПЛИС.
  * `alf_carry/` — Рабочая директория проекта Quartus с результатами синтеза.
* `firmware/firmware_pico/` — Прошивка микроконтроллера RP2040:
  * `scarry.uf2` — **Готовый скомпилированный файл прошивки (для быстрой установки).**
  * `main.cpp` / `main.c` — Основная логика работы: меню, чтение FAT32, инициализация BIST.
  * `ssd1306.c` / `ssd1306.h` / `font.h` — Драйвер и шрифты для работы с OLED-экраном.
  * `test_busdata/` — Отдельный отладочный проект для тестирования шины данных.
* `firmware/sdcard_template/` — Шаблон файлов для SD-карты (включает базовый `alf_cfg.ini`).

## Инструкции по сборке и прошивке

### 1. Прошивка ПЛИС (Quartus II)

Откройте проект в среде Altera Quartus II (рекомендуется версия v13.0sp1). Выполните полную компиляцию проекта и прошейте сгенерированный `.pof` файл в микросхему `EPM240T100C5N` через разъем JTAG, используя программатор USB-Blaster.

### 2. Прошивка RP2040 (Raspberry Pi Pico)

**Самый простой способ (использование готовой прошивки):**
1. Подключите Raspberry Pi Pico к компьютеру по USB, удерживая нажатой кнопку `BOOTSEL` на самой плате микроконтроллера.
2. В системе появится новый съемный диск (обычно называется `RPI-RP2`).
3. Просто скопируйте готовый файл `firmware/firmware_pico/scarry.uf2` на этот диск. Pico автоматически перезагрузится, и прошивка будет установлена.

**Для разработчиков (самостоятельная сборка из исходников):**
Для компиляции прошивки потребуется установленный фреймворк **Raspberry Pi Pico C/C++ SDK**. В терминале перейдите в папку прошивки и выполните:
```bash
cd firmware/firmware_pico
mkdir build && cd build
cmake ..
make
```
После успешной сборки скопируйте полученный `.uf2` файл на контроллер, как описано в шагах выше.

### 3. Подготовка SD-карты

1. Отформатируйте microSD карту в файловую систему **FAT32**.
2. Скопируйте файл `alf_cfg.ini` из папки `firmware/sdcard_template/` в корневой каталог карты.
3. Поместите образы ваших игр в корень карты или в созданные папки.
