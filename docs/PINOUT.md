# Таблицы соединений — SCARRY v1 (`alf-scar`)

## 1. Назначение выводов модуля `A1` (`Raspberry Pi Pico`)

| Пин модуля `A1` | GPIO RP2040 | Имя цепи в схеме | Назначение |
| :---: | :---: | :--- | :--- |
| **Pin 5** | `GPIO3` | `/BTN_DOWN` | Вход кнопки `SW3` (`DOWN`) через RC-фильтр `R8/R10/C20` |
| **Pin 6** | `GPIO4` | `/I2C_SDA` | Линия данных `SDA` OLED-дисплея `U7` (подтяжка `R12` 4.7K) |
| **Pin 7** | `GPIO5` | `/I2C_SCL` | Линия тактирования `SCL` OLED-дисплея `U7` (подтяжка `R13` 4.7K) |
| **Pin 10** | `GPIO7` | `/BTN_OK` | Вход кнопки `SW2` (`OK`) через RC-фильтр `R3/R4/C19` |
| **Pin 11** | `GPIO8` | `/SD_MISO` | Выход данных `DAT0` карты microSD `J2` (`SPI1 RX`) |
| **Pin 12** | `GPIO9` | `/Z80_RESET` | Управление базой NPN-ключа `Q1` (`1` = удерживать Z80 в сбросе) |
| **Pin 14** | `GPIO10` | `/SD_SCK` | Тактирование `CLK` карты microSD `J2` (`SPI1 SCK`) |
| **Pin 15** | `GPIO11` | `/SD_MOSI` | Линия команд `CMD` карты microSD `J2` (`SPI1 TX`) |
| **Pin 16** | `GPIO12` | `/BTN_UP` | Вход кнопки `SW1` (`UP`) через RC-фильтр `R1/R2/C18` |
| **Pin 19** | `GPIO14` | `/SD_CS` | Выбор кристалла `DAT3/CS` карты microSD `J2` |
| **Pin 21** | `GPIO16` | `/SPI_MISO` | Вход чтения данных из ПЛИС `EPM240` (`SPI0 RX`, Pin 18 ПЛИС) |
| **Pin 22** | `GPIO17` | `/SPI_CS/` | Выбор ПЛИС для команд SPI-моста (`SPI0 CSn`, Pin 15 ПЛИС) |
| **Pin 24** | `GPIO18` | `/SPI_SCK` | Тактирование SPI-моста ПЛИС (`SPI0 SCK`, Pin 16 ПЛИС) |
| **Pin 25** | `GPIO19` | `/SPI_MOSI` | Передача команд и образов в ПЛИС (`SPI0 TX`, Pin 17 ПЛИС) |
| **Pin 26** | `GPIO20` | `/Z80_RST_33V` | Мониторинг аппаратного сброса приставки (через `U4` пин 12) |
| **Pin 27** | `GPIO21` | `/CLK_50MHZ` | Аппаратный выход `GPOUT0` (50 МГц) на `GCLK0` ПЛИС (Pin 12) |
| **Pin 29** | `GPIO22` | `/MCU_ACTIVE` | Режим работы: `1` = Загрузка/BIST, `0` = Игра Z80 (Pin 14 ПЛИС) |
| **Pin 39** | `VSYS` | `+5V` | Вход питания `+5V` от разъема `XP1` (контакты 1, 47) |

## 3. Распиновка краевого разъема `XP1` (`ALF-LAMEL`)

* **Нечетный ряд (1..47):**
  * `1, 47` — `+5V`
  * `3` — `/*ROMCS/`
  * `5` — `/*MREQ/`, `7` — `/*IORQ/`, `9` — `/*BSRQ/`, `11` — `/*BSAK/`
  * `13` — `/*PBANK` (строб записи банка маппера)
  * `15` — `/*ROMC/` (выборка ПЗУ картриджа)
  * `17` — `/*SSRD/`, `19` — `/*INT/`, `21` — `/*WAIT/`, `23` — `/*NMI/`
  * `25` — `/*D2`, `27` — `/*D0`, `29` — `/*D1`
  * `35` — `/*D4`, `37` — `/*D5`, `39` — `/*D6`, `41` — `/*D7`
  * `43` — `/*SSWR/`, `45` — `/*RST`
* **Четный ряд (2..48):**
  * `2, 48` — `GND`
  * `4..30` (четные) — Шина адреса `/*A0 .. /*A13`
  * `36` — `/*D3`
  * `38` — `/*RST/` (активный низкий уровень сброса)
  * `40` — `/*M1/`, `42` — `/*RD/`, `44` — `/*WR/`, `46` — `/*RFSH/`
